
# Java To-Do List Application

## About Project
This is a simple Java-based To-Do List
application that helps users manage daily tasks.

## Technologies
- Java
- ArrayList
- Scanner
- Object-Oriented Programming

## Features
- Add tasks
- View tasks
- Complete tasks
- Delete tasks

## How to Run

1. Install Java JDK.
2. Download or clone this repository.
3. Open the project in VS Code.
4. Compile the program:

   javac Main.java

5. Run the program:

   java Main
